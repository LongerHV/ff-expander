# Libraries

## `ff-expander.kicad_sym` (ours)

Generated by `../gen_schematics.py`. The `XIAO_ESP32C6` symbol is our own
drawing, with pin numbers matching Seeed's footprint. Licensed CERN-OHL-S-2.0
like the rest of the hardware design.

## `Seeed_Studio_XIAO_Series.pretty/` (third party)

`XIAO-ESP32-C6-SMD.kicad_mod` and `XIAO-ESP32-C6-DIP.kicad_mod`, copied
unmodified from Seeed Studio's Open Parts Library:
https://github.com/Seeed-Studio/OPL_Kicad_Library
(folder "Seeed Studio XIAO Series Library", commit b0035c51).

International (CC BY-SA 4.0): https://creativecommons.org/licenses/by-sa/4.0/

These files are **not** covered by the repository's MIT or CERN-OHL-S
licences.

**Before publishing a PCB layout:** KiCad copies footprints into the
`.kicad_pcb`. To keep the board file purely CERN-OHL-S, replace these with
our own XIAO footprint drawn from Seeed's mechanical drawing.
